# ⚠️ ВАЖНО: Ошибка "cannot open file 'msvcrt.lib'"

## Быстрое решение (5 минут + время установки)

### ✅ ШАГ 1: Проверьте что не так

Запустите:
```cmd
check_environment.bat
```

Скрипт покажет что именно отсутствует.

---

### 🔧 ШАГ 2: Установите Build Tools

**Это обязательно для компиляции Rust на Windows!**

#### 1. Скачайте (прямая ссылка):
https://aka.ms/vs/17/release/vs_buildtools.exe

#### 2. Запустите установщик

#### 3. В окне выберите:
- ✅ **Desktop development with C++** (отметьте галочкой)

#### 4. Нажмите "Install" (справа внизу)

⏰ **Время установки**: 20-40 минут  
💾 **Размер**: 2-6 GB

#### 5. После установки ПЕРЕЗАГРУЗИТЕ компьютер

---

### 🚀 ШАГ 3: Соберите проект

```cmd
cd file_finder
cargo clean
build.bat
```

Всё должно заработать! ✅

---

## 📖 Что происходит?

Rust на Windows использует компилятор C++ от Microsoft (MSVC).  
Для работы нужны:
- Компилятор (cl.exe, link.exe)
- Библиотеки (msvcrt.lib и другие)
- Windows SDK

Всё это включено в "Visual Studio Build Tools".

## ❓ Часто задаваемые вопросы

**Q: Это бесплатно?**  
✅ Да, Build Tools полностью бесплатны

**Q: Нужна ли полная Visual Studio?**  
❌ Нет, достаточно Build Tools

**Q: У меня уже есть VS 2019/2022**  
✅ Отлично! Откройте VS Installer и убедитесь что установлен компонент "Desktop development with C++"

**Q: Есть альтернатива без установки?**  
⚠️ Можно использовать GNU toolchain (MinGW), но это менее стабильно. См. FIX_LINKER_ERROR.md

**Q: Могу я собрать на Linux?**  
✅ Да, в WSL (Windows Subsystem for Linux). Там всё проще, но exe будет для Linux

## 🆘 Если ничего не помогает

1. Убедитесь что установили именно "Desktop development with C++"
2. Перезагрузите компьютер после установки
3. Откройте НОВОЕ окно командной строки
4. Запустите `check_environment.bat` для диагностики
5. Попробуйте из "Developer Command Prompt for VS"

## ✅ Проверка успешной установки

После установки Build Tools запустите:
```cmd
where link.exe
```

Должно показать путь:
```
C:\Program Files\Microsoft Visual Studio\2022\BuildTools\VC\Tools\MSVC\14.xx\bin\Hostx64\x64\link.exe
```

Если путь показывается - всё готово! Можно собирать проект.
