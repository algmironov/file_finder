# 🎉 FileFinder - Готово к использованию!

Поздравляю! Ваше CLI приложение для поиска больших файлов готово.

## 🚀 Что делать дальше?

### ⚠️ ВАЖНО: Требования для Windows

Для компиляции Rust на Windows нужны **Visual Studio Build Tools**.

**Проверьте прямо сейчас:**
```cmd
check_environment.bat
```

**Если Build Tools отсутствуют:**
1. Читайте → **FIX_THIS_FIRST.md** ⭐
2. Скачайте: https://aka.ms/vs/17/release/vs_buildtools.exe
3. Установите "Desktop development with C++"
4. Перезагрузите компьютер

Это нужно сделать **один раз**. После этого всё будет работать.

---

### Шаг 1: Установите Rust (если еще не установлен)

**Windows:**
1. Скачайте: https://rustup.rs/
2. Запустите `rustup-init.exe`
3. Следуйте инструкциям

**Проверка:**
```bash
rustc --version
cargo --version
```

### Шаг 2: Соберите проект

**Windows:**
```cmd
cd file_finder
build.bat
```

**Linux/Mac:**
```bash
cd file_finder
chmod +x build.sh
./build.sh
```

**Или вручную:**
```bash
cd file_finder
cargo build --release
```

Исполняемый файл будет в:
- Windows: `target\release\file_finder.exe`
- Linux/Mac: `target/release/file_finder`

### Шаг 3: Запустите!

```bash
# Windows
target\release\file_finder.exe

# Linux/Mac
./target/release/file_finder
```

## 🎯 Быстрый тест

После сборки попробуйте:

```bash
# Справка
file_finder --help

# Интерактивный режим
file_finder

# Поиск файлов больше 500MB
file_finder --min-size 500MB

# Поиск видео файлов
file_finder -e mp4,mkv,avi --min-size 200MB

# Поиск дубликатов
file_finder --min-size 100MB --duplicates
```

## ❓ Частые вопросы

**Q: Нужен ли мне опыт в Rust?**
A: Нет! Проект готов к использованию. Если хотите изменять код - читайте RUST_GUIDE.md

**Q: Как долго компилируется?**
A: Первая сборка: 2-5 минут. Последующие: 10-30 секунд.

**Q: Какой размер готового файла?**
A: ~6-8 MB (можно сжать до ~2-3 MB с UPX)

**Q: На каких ОС работает?**
A: Windows, Linux, macOS

**Q: Безопасно ли это?**
A: Да! Исходный код открыт, вы можете проверить всё сами.
